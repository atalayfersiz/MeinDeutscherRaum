# Gemini Chat / Ders Notu - 03.11.2026
Konu: B1 Beruf und Bewerbung

Yeni kelimeler:
- die Bewerbung, -en (başvuru / application)
- das Vorstellungsgespräch, -e (iş mülakatı / job interview)
- der Arbeitgeber, - (işveren / employer)
- die Herausforderung, -en (meydan okuma, zorluk / challenge)
- die Beständigkeit (istikrar, süreklilik / consistency)
- das Labyrinth, -e (labirent / maze)
- der Projektleiter, - (proje yöneticisi / project manager)

Fiiller ve edatlar:
- vorbereiten auf + Akk (bir şeye hazırlanmak / to prepare for): Er bereitet sich auf das Vorstellungsgespräch vor.
- anrufen bei / anrufen + Akk (aramak / to call): Er ruft seine Familie an.
- entsprechen + Dat (uygun düşmek, denk gelmek / to correspond to): Das Gehalt entspricht seinen Erwartungen.
- anbieten (teklif etmek / to offer): Der Chef bietet ihm eine Stelle an.
- verlaufen (geçmek, seyretmek / to proceed): Das Treffen verlief positiv.
